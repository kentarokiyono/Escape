# ストーリーマップの書き方

ストーリーモードのマップは `src/story/maps.js` に文字で書く。1文字 = 1m。全マップとも 44×32。
3F の穴に落ちると 2F の同じ位置へ落ちるので、マップの大きさはそろえる。

## 確認方法

```bash
node tools/check-maps.mjs
```

次をチェックする。到達できないものがあれば、その位置を表示する。

- 行の長さがそろっているか
- 開始地点から、目的物（階段・日誌・配電盤・リフト・印など）に到達できるか

扉はすべて開いているものとして判定する。

## 凡例

### 構造・床

| 文字 | 意味 |
|---|---|
| `#` | 壁（天井まで） |
| `.` | 床 |
| `_` | 小上がり（+0.35m）。人は上がれる。ロボットは上がれない |
| `+` | ステージ（+0.6m）。階段が必要 |
| `=` | 中二階（+2.6m）。下は埋まっている。低い側との境には手すりが自動で付く |
| `,` | 一段低い床（-0.4m）。洗い場など |
| `^` `v` `<` `>` | 階段（人のみ）。矢印の向きに上る。両端の床の高さを自動でつなぐ |
| `A` `V` `{` `}` | スロープ（ロボットも通れる）。それぞれ北・南・西・東に向かって上る |
| `O` | 崩落した床（穴）。落ちると `below` の階の同じ位置へ |
| `d` | ダクト（しゃがみ専用通路）。ロボットは入れない。壁の中に置くと、上が壁になる |

### 扉

| 文字 | 意味 |
|---|---|
| `D` | 出入口（上に垂れ壁） |
| `K` | 施錠扉。`doors` で設定する（`need`: 必要なアイテム / `thumb`: サムターンのある側 n,s,e,w / `locked`: イベントで開く） |
| `S` | シャッター。電源が入ると開く。隣り合う `S` は1枚の扉になる |

### 家具（同じ文字が隣り合うと1つにまとまる）

| 文字 | 意味 |
|---|---|
| `T` | テーブル（3マス以上は長テーブル＋椅子） |
| `t` | タブレット付きテーブル（囮に使える） |
| `R` | 丸テーブル |
| `B` | ボックス席（3×2 が基本） |
| `Z` | 座卓 |
| `C` | 厨房カウンター |
| `H` | 棚 |
| `M` | 機械キャビネット |
| `X` | 瓦礫 |
| `Q` | 柱 |
| `L` | ロッカー（隣の壁を背にする） |

### 設備・配置

| 文字 | 意味 |
|---|---|
| `P` | 配電盤（隣の壁に付く）。マップ設定の `breaker` で鍵の要否を指定する |
| `c` | 監視カメラ（開けた方向を自動で向く） |
| `m` | 監視モニター卓 |
| `F` | 配膳リフト/エレベーター。行き先は `lifts.F` で指定する。背後の壁をシャフトにする |
| `x` | 脱出口（隣の外壁に付く） |
| `U` | 上り階段の入口。行き先はマップの `up` |
| `@` | 開始地点 |
| `r` | 巡回ロボット |
| `z` | 待機ロボット（ドック）。イベントで起動する |
| `j` | サキの日誌（全マップの合計が真エンドの条件） |
| `k` / `a` | ロボットモード用。鍵の置き場所 / 客の出現位置 |
| `1`〜`9` | マップごとの `marks` で意味を決める（trigger / item / robot / console / lift） |
