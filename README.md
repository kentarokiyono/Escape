# お席へご案内します ―廃墟階―

元ファミレスの廃ビルから脱出する一人称ホラー。給仕ロボットと統括AI「FR-002」は、閉店から10年経った今も“営業中”。

## 起動

ES Modules を使うため、`file://` で直接開くと動かない。ローカルサーバーを立てて開く。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。three.js は `vendor/` に同梱しているので、ネット接続は不要。

- `?seed=12345`: フリーモードの建物を固定する
- `?debug`: `window.game` / `window.app` を公開する（デバッグ用）
- `?touch`: PC でもタッチ操作の画面にする（確認用）

## モード

| モード | 内容 |
|---|---|
| ストーリー | 手作りの固定マップで、序章〜終章の全7章。章の開始時点を自動保存し、「つづきから」で再開できる。捕まると章の始めからやり直し |
| フリー | 自動生成の5階建て。5F のマスターキーを取り、1F から脱出する |
| ロボット | 裏エンドで解放。プレイヤーは給仕ロボット。鍵を探して脱出を狙う客4人を、全員捕まえる |

### ストーリーの結末

- **通常エンド**: 脱出する
- **真エンド**: サキの日誌（全7枚）を集めて脱出する
- **裏エンド**: ストーリーの累計プレイ時間が60分を超える（やり直しの時間も含む）。時間の表示はない。近づくと館内放送が流れる

## 操作

スマホ・タブレットは横画面で遊べる（縦画面では横向きを促す表示が出る）。
- 画面の左側をドラッグ: 移動
- 画面の右側をドラッグ: 視点
- ボタン: 調べる・走る（押している間）・しゃがむ（切替）・ライト・マップ・一時停止
- 監視モニター中: ◀ ▶ でカメラ切替、戻るで終了
- 開始時に全画面化と横向き固定を試みる（Android のみ有効）
- タッチ端末では、画質の初期値が「低」になる

キーボードの場合:

| キー | 動作 |
|---|---|
| マウス | 視点 |
| WASD | 移動 |
| Shift | ダッシュ（スタミナ消費） |
| C | しゃがむ（足音が小さくなり、低い遮蔽物に隠れられる。ダクトを通れる） |
| E | 調べる / ロッカーに隠れる / 配電盤・扉・リフト・監視モニターの操作 / 拾う |
| F | ライト ON/OFF |
| M | マップ（踏破した場所のみ） |
| Esc | 一時停止 |
| A / D | 監視モニターのカメラ切替 |

## 仕組み

### 起伏

| 要素 | 人 | ロボット |
|---|---|---|
| 段差・小上がり（〜0.45m） | 上れる | 上れない |
| スロープ | 通れる | 通れる |
| 階段・中二階 | 上れる | 上れない |
| 崩落した床 | 落ちると下の階へ | 近づかない |
| ダクト | しゃがむと通れる | 入れない |

### ギミック

| 要素 | 内容 |
|---|---|
| 配電盤 | 照明・監視カメラ・シャッター・リフトが電源に連動する。切れば監視カメラも止まる |
| 施錠扉 | カードキーで開く扉と、内側のサムターンで開く扉がある |
| 監視カメラ | 映り続けると近くのロボットが呼ばれる。監視モニターから全カメラの映像を見られる |
| 配膳リフト / エレベーター | 階を移動できる。動作音で、出発地と到着地のロボットが集まる |
| フリーモードの上り階段 | 2F〜4F は、暗証番号・シャッター・カードキーのどれかで施錠されている |
