# お席へご案内します ―廃墟階―

元ファミレスの廃ビルから脱出する一人称ホラー。5F のマスターキーを取り、1F の脱出口から逃げる。

## 起動

ES Modules を使うため、`file://` で直接開くと動かない。ローカルサーバーを立てて開く。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。three.js は `vendor/` に同梱しているので、ネット接続は不要。GitHub Pages ならそのまま公開できる。

- `?seed=12345`: 建物（レイアウト・暗証番号・階段位置）を固定する
- `?debug`: `window.game` を公開する（デバッグ用）

## 操作

| キー | 動作 |
|---|---|
| マウス | 視点 |
| WASD | 移動 |
| Shift | ダッシュ（スタミナ消費） |
| C | しゃがむ（足音小・低い遮蔽物に隠れられる） |
| E | 調べる / ロッカーに隠れる / 階段 / タブレット囮 / メモを読む |
| F | ライト ON/OFF |
| M | マップ（踏破した部屋のみ） |
| Esc | 一時停止 |

## ルール

- 2F→3F、3F→4F、4F→5F の上り階段には暗証番号が必要。番号は、その階の床に落ちている黄色いメモに書いてある。
- ロボットは視覚と聴覚で探す。
  - 視覚: 前方 130°。ライト点灯中は遠くからでも見つかる。
  - 聴覚: 走ると約 13m、歩くと約 6m、しゃがむと約 1.5m 先まで足音が届く。水たまりの上では大きくなる。
- 見られている最中にロッカーへ隠れると、ロッカーを調べに来る。
- 隠れている間は増援が 3 倍速で来る。
- マスターキーを取ると警報が鳴る。全階で警戒が強まる。

## 構成

```
index.html          画面骨格・importmap
css/style.css       UI スタイル
src/main.js         起動・入力・設定・メインループ
src/game.js         状態遷移・フロア管理・インタラクション・ライト/カメラ/露出
src/level.js        フロア生成（部屋/迷路・小物・ロッカー・階段・メモ）、静的メッシュの結合
src/physics.js      当たり判定（バケット分割）・視線/ナビ用グリッド
src/nav.js          フローフィールド経路探索（LRU キャッシュ）
src/robot.js        ロボットのモデルと AI（巡回/警戒/追跡/捜索/囮/ロッカー確認）
src/player.js       移動・スタミナ・しゃがみ・ヘッドボブ・足音
src/audio.js        WebAudio（HRTF 立体音響・残響・遮蔽・環境音・心拍）
src/textures.js     手続き生成テクスチャ（カラー/法線/ラフネス）
src/postfx.js       ブルーム・トーンマップ・フィルムグレイン・色収差
src/minimap.js      マップ描画
src/ui.js           HUD・オーバーレイ・暗証番号パネル
src/config.js       定数（階構成・速度・知覚範囲）
vendor/three/       three.js r160（MIT）
```
