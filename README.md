# お席へご案内します ―廃墟階―

元ファミレスの廃ビルから脱出する一人称ホラー。給仕ロボットと統括AI「FR-002」は、閉店から10年経った今も“営業中”。

## 起動

ES Modules を使うため、`file://` で直接開くと動かない。ローカルサーバーを立てて開く。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。three.js は `vendor/` に同梱しているので、ネット接続は不要。

- `?seed=12345`: フリーモードの建物を固定する
- `?debug`: `window.game` / `window.app` を公開する（デバッグ用）
- `?touch`: PC でもタッチ操作の画面にする（確認用）

## モード

| モード | 内容 |
|---|---|
| ストーリー | 手作りの固定マップで、序章〜終章の全7章。章の開始時点を自動保存し、「つづきから」で再開できる。捕まると章の始めからやり直し |
| フリー | 自動生成の5階建て。5F のマスターキーを取り、1F から脱出する |
| ロボット | 裏エンドで解放。プレイヤーは給仕ロボット。鍵を探して脱出を狙う客4人を、全員捕まえる |

### ストーリーの結末

- **通常エンド**: 脱出する
- **真エンド**: サキの日誌（全7枚）を集めて脱出する
- **裏エンド**: ストーリーの累計プレイ時間が60分を超える（やり直しの時間も含む）。時間の表示はない。近づくと館内放送が流れる

## 操作

スマホ・タブレットは横画面で遊べる（縦画面では横向きを促す表示が出る）。
- 画面の左側をドラッグ: 移動
- 画面の右側をドラッグ: 視点
- ボタン: 調べる・走る（押している間）・しゃがむ（切替）・ライト・マップ・投げる（押して離す）・停止（リモコン）・一時停止
- 監視モニター中: ◀ ▶ でカメラ切替、戻るで終了
- 開始時に全画面化と横向き固定を試みる（Android のみ有効）
- タッチ端末では、画質の初期値が「低」になる

キーボードの場合:

| キー | 動作 |
|---|---|
| マウス | 視点 |
| WASD | 移動 |
| Shift | ダッシュ（スタミナ消費） |
| C | しゃがむ（足音が小さくなり、低い遮蔽物に隠れられる。ダクトを通れる） |
| E | 調べる / ロッカーに隠れる / 配電盤・扉・リフト・監視モニターの操作 / 拾う |
| G（長押し） | 物を投げる（離すと投げる） |
| R | 停止リモコン |
| V | センサー表示の切替 |
| F | ライト ON/OFF |
| M | マップ（踏破した場所のみ） |
| Esc | 一時停止 |
| A / D | 監視モニターのカメラ切替 |

## 追加要素

### ロボットを止める
- **停止リモコン**: 画面中央の先 7m 以内にいるロボット1台を、正面からでも永久に止める。1回ごとに電池を1本使う。電池は館内で拾う。キーは R。
- **充電切れ**: ロボットにはバッテリー残量があり、追跡すると急速に減る。残量が少なくなると充電ドックへ戻り、その間は反応しない。ドックに着く前に切れると、その場で永久に止まる。
- 止めたロボットからは型番プレートを外せる。外すと図鑑に登録される。
- ロボットは5機種（巡回型・案内型・厨房型・警備型・旧型）。速度・視覚・バッテリーが違う。

### 理系要素
- **配電盤の容量**: 定格は 30A（100V）。照明 8A・監視カメラ 6A・シャッター 10A・リフト 14A を、配分して ON/OFF する。超えるとブレーカーが落ちる。
- **暗号の暗証番号**（フリーモード）: 2F は2進数、3F はレシート（税込合計の下4桁）、4F は16進数で書かれている。
- **投げる**: 皿や空き缶を G 長押しで投げる。投げる強さで飛距離が変わる。重力で放物線を描き、壁や床で跳ね返る。割れた音でロボットをおびき寄せる。
- **FR-002 技術資料**（3種）: 読むと、ロボットの視野（床の扇形）・自分の足音の届く範囲（輪）・ロボットの電池残量が見えるようになる。V で表示を切り替える。

### やりこみ
- **実績**（21個）と**図鑑**（ロボット5機種・メモ8枚）。タイトルの「実績・図鑑」で確認できる。
- **章ランク**: 章ごとの時間と発見回数で S〜C を付ける。「章を選ぶ」から、到達した章に再挑戦できる。
- **今日の建物**: 日付で建物が決まるフリーモード。その日の記録を残す。
- **難易度**（やさしい / ふつう / むずかしい）と**ハードコア**（ストーリーで捕まると序章から）。タイトル下の設定で選ぶ。

## 仕組み

### 起伏

| 要素 | 人 | ロボット |
|---|---|---|
| 段差・小上がり（〜0.45m） | 上れる | 上れない |
| スロープ | 通れる | 通れる |
| 階段・中二階 | 上れる | 上れない |
| 崩落した床 | 落ちると下の階へ | 近づかない |
| ダクト | しゃがむと通れる | 入れない |

### ギミック

| 要素 | 内容 |
|---|---|
| 配電盤 | 照明・監視カメラ・シャッター・リフトが電源に連動する。切れば監視カメラも止まる |
| 施錠扉 | カードキーで開く扉と、内側のサムターンで開く扉がある |
| 監視カメラ | 映り続けると近くのロボットが呼ばれる。監視モニターから全カメラの映像を見られる |
| 配膳リフト / エレベーター | 階を移動できる。動作音で、出発地と到着地のロボットが集まる |
| フリーモードの上り階段 | 2F〜4F は、暗証番号・シャッター・カードキーのどれかで施錠されている |
